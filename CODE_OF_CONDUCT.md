# Code of Conduct

## Our Standards

This project is for practical, defensive supply-chain guidance. Contributors are expected to:

- be respectful and constructive in issues, pull requests, and reviews
- assume good intent while still being precise about technical risk
- focus disagreement on evidence, tradeoffs, and project scope
- avoid harassment, personal attacks, discriminatory language, or doxxing
- respect private security reports and avoid publishing sensitive details before coordinated disclosure

## Scope

This code of conduct applies to project spaces, including GitHub issues, pull requests, discussions, documentation, and any project-controlled communication channels.

## Reporting

Report unacceptable behavior or sensitive conduct concerns to the maintainer privately when possible. For security-sensitive reports, follow [SECURITY.md](SECURITY.md).

## Enforcement

Maintainers may edit or remove comments, close issues or pull requests, block participants, or take other reasonable action to keep the project useful and safe. Enforcement decisions should be proportional, documented where appropriate, and focused on protecting contributors and users.
